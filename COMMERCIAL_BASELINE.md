## Historical lineage

No OSI-approved product-code predecessor exists in this repository history.
No Creative Commons grant covered the product code or register. That finding
does not make the historical engine all-rights-reserved: beginning with
`7d1d980fa92cf0591dacac06f98391b23e93e9f4`, Engine Materials were distributed
under PolyForm Noncommercial 1.0.0, which supplied affirmative noncommercial
permissions but is not an OSI-approved open-source license.

The initial commit, `ea7ce8de2dba2d51ad7ad12ab9f9f30e86e046f8`,
contained only product documentation. It described the intended source-available
engine and exclusive register scopes, but did not contain the referenced license
texts, engine implementation, or register. The first complete code-bearing
snapshot was `7d1d980...`. Commits `d6cc85b...`, `f8ce528...`, and `029ca145...`
continued the PolyForm engine scope and the separate Exclusive Register License.

The Relational Systems Register never received a general functional-use grant
in this repository. Its existing custom license nevertheless supplied limited
copying for receipt, storage, backup, and visual evaluation, and that historical
grant remains effective for copies to which it attached.

## Prospective effect

From the baseline revision forward, current Engine Materials are identified in
`license-scope.json` as `engine-proprietary` and governed by the Hayden Howard
Proprietary Product and Source License 1.0. Register Materials remain separately
classified as `register-exclusive` under the unchanged Lattice Exclusive
Register License 1.0. Historical and third-party license texts remain in the
administrative scope as evidence, not as a new default engine grant.

This baseline does not revoke, narrow, or rewrite permissions validly attached
to earlier distributed copies. Those permissions remain governed by their own
terms. This baseline does not determine whether an earlier permission applies
to a different copy or later distribution. It does not alter statutory
exceptions, platform-supplied rights, independently created material, or
third-party rights. It does not set a price, create a paid offering, publish a
package, change repository visibility, or authorize a deployment or release.

## Release evidence

The baseline is complete only when the introducing commit contains the aligned
root notice, proprietary terms, unchanged register terms, scope manifest and
schema, package metadata, README and licensing documentation, adversarial review,
and executable scope checks. Record the introducing commit SHA in release or
approval evidence after commit creation; a content-addressed commit cannot embed
its own final SHA in the file from which that SHA is calculated.
